# Практическая работа №1. Основы Git

Выполненные шаги:
1. Инициализирован локальный репозиторий (git init).
2. Созданы файлы test1.txt, test2.txt и сделан первый коммит.
3. Добавлен файл .gitignore для игнорирования файлов по шаблону.
4. Изменен файл test1.txt и сделан второй коммит.
5. Создана ветка vetka1, в ней изменен файл test2.txt и сделан коммит.
6. Выполнено слияние ветки vetka1 в main в режиме fast-forward.
7. В ветке main внесены новые изменения в test2.txt и зафиксированы коммитом.
8. В ветке vetka1 изменен тот же файл, вызван конфликт слияния и разрешен вручную.
9. Просмотрена история коммитов и ветвлений через git log --graph --oneline --all.
10. Создан удаленный репозиторий на GitHub, локальный репозиторий связан с ним и отправлен коммит (git push).
11. На GitHub создан файл README.md.
12. Изменения из удаленного репозитория стянуты в локальный через git pull.

Список использованных команд:
1. git init - инициализация репозитория.
2. git add . - добавление файлов в индекс.
3. git commit -m - фиксация изменений.
4. git checkout -b - создание и переход на новую ветку.
5. git merge - слияние веток.
6. git log --graph --oneline --all - визуализация структуры коммитов.
7. git remote add origin - привязка удаленного репозитория.
8. git push - отправка изменений на GitHub.
9. git pull - получение изменений с GitHub.
